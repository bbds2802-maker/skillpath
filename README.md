# SkillPath

把学习目标变成课程计划，结合真实 B站 / YouTube 教程、页面内播放器、学习笔记与完成进度。

- [在线使用](https://bbds2802-maker.github.io/skillpath/)
- [Cloudflare 备用入口](https://skillpath-entry.pages.dev/app/)

## 2026-11-01 网页更新

采用 Figma RT / Soft ABS 组件库：米白 ABS 材质、氧化橙强调色、微凸按钮与浅凹输入槽。保留手机界面比例、课程日历、视频播放、笔记与进度功能。

联网前在设置中连接服务并完成访问验证。Groq 和 YouTube API 密钥由后端保管，访客无需输入。访问凭证最长两小时，不代表注册账号。

当前计划、笔记与完成状态保存在当前浏览器，不跨设备或域名同步；清除浏览器数据会删除本地记录。目前同时保留一份当前计划，创建新计划会先提示替换。未连接或服务失败时会明确显示本地大纲，不虚构视频。

在 iPhone 上使用 Safari 打开网页，可从分享菜单添加到主屏幕。B站通过官方外链播放器播放，支持 `?p=2` 等合集分集链接；YouTube 使用原有播放器。视频是否可播放取决于平台限制和本机网络。

新计划默认匹配 B站，可在创建时额外选择 YouTube 作为补充。生成课时后会自动匹配真实视频，支持合集分集；课时内也可继续搜索、添加视频。

B站当前限制 Cloudflare 的实时搜索请求。服务会自动切换到已核验教程库，覆盖首页的滑板、吉他、绘画、编程、摄影、烹饪、钢琴、瑜伽八类技能，页面标明「教程库匹配」。库中保存公开标题、作者、时长和分集目录，不下载视频。未覆盖的课题会明确显示未匹配，不编造链接。

教程库于 2026-11-01 核验，不保证视频之后始终公开或适合每个学习方向。维护者可手动运行 `tools/refresh-bilibili-catalog.cjs` 更新；刷新遇到来源限制会停止，没有自动定时任务。完整链接导入仍然保留。
