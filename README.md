# SkillPath

把学习目标变成课程计划，结合真实 B站 / YouTube 教程、页面内播放器、学习笔记与完成进度。

- [在线使用](https://bbds2802-maker.github.io/skillpath/)
- [Cloudflare 备用入口](https://skillpath-entry.pages.dev/app/)

## 2026-11-01 网页更新

采用 Figma RT / Soft ABS 组件库：米白 ABS 材质、氧化橙强调色、微凸按钮与浅凹输入槽。保留手机界面比例、课程日历、视频播放、笔记与进度功能。

联网前在设置中连接服务并完成访问验证。Groq 和 YouTube API 密钥由后端保管，访客无需输入。访问凭证最长两小时，不代表注册账号。

当前计划、笔记与完成状态保存在当前浏览器，不跨设备或域名同步；清除浏览器数据会删除本地记录。目前同时保留一份当前计划，创建新计划会先提示替换。未连接或服务失败时会明确显示本地大纲，不虚构视频。

在 iPhone 上使用 Safari 打开网页，可从分享菜单添加到主屏幕。B站通过官方外链播放器播放，支持 `?p=2` 等合集分集链接；YouTube 使用原有播放器。视频是否可播放取决于平台限制和本机网络。

新计划默认匹配 B站，可在创建时额外选择 YouTube。B站路径按每课的学习目标实时查询 Qovia 的 B站搜索 API，再筛选相关视频；不从固定教程库选取，也不会在搜索失败时自动回退到教程库。

B站实时搜索需要在现有 Worker 的 Secret 中配置 `BILIBILI_API_KEY`（Qovia 密钥，仅需 `raw:bilibili` 权限）。密钥只由后端发送给 `api.qovia.ai`，网页访客看不到。请求失败、额度不足、只返回缓存资料或没有相关结果时，会明确提示并保留课程大纲。

实时结果保留本次查询词、查询时间及供应商实时来源标记。长计划按最多六课一批查询，并逐批保存；视频通过 B站官方外链播放器播放，不下载或转存视频。原有已保存课程与笔记会保留，包括旧版教程库资料；旧资料不会被标成新的实时搜索结果。

2026-11-02 已完成线上实时搜索验收：用旧教程库未包含的“陶艺拉坯”生成两课，两次独立查询分别返回 `BV1o64y1B76L` 和 `BV1xRxG65EKB`，采集时间与本次请求一致。两条结果均已通过网页内 B站官方播放器播放验证。验收记录保存在本地发布记录中，用户原有学习计划和笔记未被替换。
